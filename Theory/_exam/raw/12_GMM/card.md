# Summary Card — Gaussian Mixture Models (GMM)

*(Formato indicizzato per asse d'esame, allineato alle altre card per il confronto Prompt 2.)*

| Asse | Contenuto chiave |
|---|---|
| **Motivation / goal** | **Density estimation** di distribuzioni generiche come **somma pesata di gaussiane** (approssima qualunque densità regolare con abbastanza dati). Usi: density estimation, **clustering** (generalizza K-means), classificatore **generativo** (una GMM per classe). $\mathcal{D}$ trattato come **unlabeled**. |
| **Mathematical formulation** | $f_X(x)=\sum_{c=1}^K w_c\,\mathcal{N}(x;\mu_c,\Sigma_c)$, con $\sum_c w_c=1,\ w_c\ge0$. Parametri $\theta=(\mathcal{M},\mathcal{S},\mathbf{w})$. **Latent-variable view**: marginale di un joint con prior **categorico** $P(C_i=c)=w_c$ e conditional $\mathcal{N}(x;\mu_c,\Sigma_c)$. Log-lik $\ell(\theta)=\sum_i\log\sum_c w_c\mathcal{N}(x_i;\mu_c,\Sigma_c)$ (log di una somma → no closed form). |
| **Training** | **EM** (Expectation-Maximization). **E-step**: responsabilità $\gamma_{c,i}=\frac{w_c\mathcal{N}(x_i;\mu_c,\Sigma_c)}{\sum_{c'}w_{c'}\mathcal{N}(x_i;\mu_{c'},\Sigma_{c'})}$. **M-step**: $\mu_c^*=F_c/N_c$, $\Sigma_c^*=S_c/N_c-\mu_c^*\mu_c^{*T}$, $w_c^*=N_c/N$ con statistiche $N_c=\sum_i\gamma_{c,i}$, $F_c=\sum_i\gamma_{c,i}x_i$, $S_c=\sum_i\gamma_{c,i}x_ix_i^T$. Likelihood **monotòna non decrescente**; converge a punto stazionario (dipende da init). Versione **soft** del training hard-assignment. |
| **Inference** | Per classificazione closed-set: una GMM per classe, $f_{X_t|C_t}(x_t|c)=\sum_{k=1}^{K_c}w_{c,k}\mathcal{N}(x_t;\mu_{c,k},\Sigma_{c,k})$, poi Bayes: $P(C_t=c|x_t)\propto P(C_t=c)\,f_{X_t|C_t}(x_t|c)$. **Clustering**: $\arg\max_c\gamma_{c,i}$. **Open-set**: GMM per la classe "none-of-the-others" eterogenea (sub-cluster). |
| **Decision rule (binaria)** | LLR generativa con densità class-conditional **mistura**: $\mathrm{llr}(x_t)=\log\frac{f(x_t|c_1)}{f(x_t|c_0)}\gtrless-\log\frac{P(c_1)}{P(c_0)}$. Boundary **non-lineare arbitrario** (non più solo quadratico): la flessibilità dipende da $K_c$. |
| **Decision rule (multiclasse)** | $\arg\max_c[\log f_{X|C}(x_t|c)+\log P(C=c)]$, con $f_{X|C}$ mistura di gaussiane. Nessun limite sul numero di classi; prior aggiustabile a deployment. |
| **Assumptions** | Ogni componente è **gaussiana**; densità = combinazione convessa di componenti ($\sum w_c=1$). Cluster membership = **variabile latente** (categorica). Campioni i.i.d. dato $\theta$. |
| **Variants** | **Full**: $\Sigma_c$ piena per componente. **Diagonal**: $\Sigma_c$ diagonale (≠ Naive Bayes!). **Tied GMM**: $\Sigma$ condivisa **tra le componenti di una stessa classe** (≠ Tied MVG che condivide tra classi). **K-means**: caso limite (hard-assignment + $\Sigma_c=I$, $w_c=1/K$). Init: **K-means** o **LBG** (split $\mu_c^\pm=\mu_c\pm\varepsilon$). |
| **Limitations** | **Likelihood illimitata** con $\ge2$ componenti → modelli **degeneri** ($\Sigma_c\to0$) e instabilità numerica (servono euristiche/covarianze vincolate). EM → solo **ottimi locali** (multipli restart). **Scelta di $K$**: la likelihood cresce sempre con $K$ → serve **cross-validation**. Servono abbastanza dati; score open-set spesso **non calibrati**. |
